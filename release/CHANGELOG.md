# 版本更新记录

所有版本的更新记录。当前最新版本：**v3.1.2**

[English](./CHANGELOG.en.md) | [العربية](./CHANGELOG.ar.md)

---

## v3.1.2 (2026-11-13)

- 更新工具与官网 logo 为新版设备互传图标
- 遥测开启时不再输出启动日志，关闭时仍显示 `Telemetry: disabled`

## v3.1.1 (2026-11-12)

- 修复文件或图片消息复制时得到相对地址的问题，现在会复制当前服务下的完整 URL

## v3.1.0 (2026-11-11)

- 软件启动后直接进入公共中转站，桌面端自动打开居中邀请弹窗，手机端按需打开
- 新增更大的二维码、全屏预览、设备在线状态切换和响应式设备列表
- 统一公共中转站与普通房间的邀请弹窗，支持房间码、复制邀请链接和房主重新生成房间码
- 新增房间级自动清理策略，房主可选择 7 天、30 天或永久保留
- 会话列表仅在收到或成功发送新消息时置顶，并补充完整阿拉伯语界面与 RTL 支持
- 新建房间支持随机生成名称，并完善设备标识、历史迁移与回归测试

## v3.0.2 (2026-11-09)

- 修复 Windows 打开缓存目录时目录已成功打开但仍提示“打开失败”的问题

## v3.0.1 (2026-11-08)

- 新增匿名使用统计：装机量、宿主活跃、宿主下用户数及消息类型分布
- 官方安装包默认启用匿名统计，可通过 --no-telemetry 或 CHATTRANSFER_TELEMETRY=off 关闭
- 优化启动日志，集中展示运行时、监听地址、数据目录、缓存目录和保留策略
- 修复遥测队列在首批发送后额外等待 5 秒的问题，并提升端到端测试稳定性

## v3.0.0 (2026-11-07)

- 新增多房间会话：支持创建房间、二维码或房间码加入、无刷新切换，并按房间隔离消息、附件和在线状态
- 新增完整房间生命周期：成员退出、房主解散、房主自动移交，最后一名成员退出后自动清理
- 默认房间升级为“公共大厅”，增加公共标识，并禁止改名、退出和解散
- 普通房间支持闲置自动删除，默认 7 天，可通过启动参数或环境变量调整或关闭
- 公共大厅支持消息和附件保留期限，并将服务器清理权限收紧到实例管理员
- 优化房间邀请、房间名同步、在线人数统计和房间内批量下载隔离
- 修复 iOS 会话高亮异常，以及移动端锁屏解锁后使用旧房间码重连失败的问题
- 新增 SQLite 迁移、房间生命周期、保留策略和配置回归测试

## v2.0.18 (2026-11-01)

- 新增批量下载附件：可从常用功能选择全部附件，或直接在消息中多选图片和文件下载
- 支持附件预览、筛选、全选及 ZIP 打包下载
- 修复桌面端刚上传文件因临时消息 ID 无法批量下载的问题，并兼容历史临时 ID
- 修复版本更新记录关闭后切换语言无法再次打开的问题
- 版权与版本信息支持跳转 GitHub 仓库，并新增项目 Star 引导

## v2.0.17 (2026-10-29)

- 修复首页和常用功能底部版权信息显示为空的问题
- 优化版本信息加载，避免重复请求

## v2.0.16 (2026-10-27)

- 修复旧版 Linux glibc 环境下 SQLite 原生模块无法加载的问题
- 恢复对旧版企业 Linux 发行版的兼容性
- 锁定 SQLite 与预编译安装工具的兼容版本

## v2.0.15 (2026-10-27)

- 修复服务重启后文件消息无法展示和打开的问题
- 修复同一浏览器重启后用户 ID 变化，导致自己发送的消息显示为收到消息的问题
- 修复 pin 消息时聊天窗口自动滚动到底部的问题

## v2.0.14 (2026-10-21)

- 修复 Node.js 22 下 npm 安装失败的问题
- 升级 SQLite 原生模块到 6.0.1，优先使用兼容新 Node 的预编译二进制
- npm 运行环境最低要求调整为 Node.js 20.17

## v2.0.13 (2026-10-20)

- 修复缓存目录可设置为文件系统根目录的安全问题
- 缓存目录校验会拒绝受保护目录及其父级，并解析符号链接真实路径
- 静态文件服务仅暴露缓存目录下的 `files` 子目录
- 保存缓存目录配置前增加写入权限校验
- 启动时校验已保存缓存目录，不安全时自动回退默认目录

## v2.0.12 (2026-10-19)

- 优化首次启动流程：自动生成默认昵称并直接进入聊天，无需手动填写
- 保留常用功能中的昵称修改入口，修改后仍会保存并同步

## v2.0.11 (2026-10-18)

- 修复 CLI 默认端口被误判为显式指定的问题，端口不可用时恢复自动递增重试
- 默认端口从 55555 调整为 55556，避开 macOS 系统保留端口
- CLI 启动失败时返回非零退出码，便于脚本和自动化流程判断

## v2.0.10 (2026-10-18)

- 新增 npm 分发方式：支持 `npx chattransfer` 和 `npm install -g chattransfer`
- 新增 CLI 参数：`--host`、`--port`、`--data-dir`、`--public-url`、`--no-browser`、`--version`、`--help`
- 新增 npm 自动发布流程，发布前自动测试、构建前端并校验包内容
- 优化 npm 运行时数据目录，配置、上传文件和 SQLite 数据不再写入全局包目录
- 修复 Linux 无桌面环境启动兼容性，并支持通过 `xdg-open` 打开浏览器和缓存目录

## v2.0.9.3 (2026-10-11)

- 新增服务端 SQLite 聊天历史：群聊和私聊消息落盘，新设备与离线设备上线后可同步历史
- 新增历史消息游标增量同步与消息去重，修复历史文本气泡空白问题
- 新增「清空我的本地记录」和「清空服务器会话历史」，后者会删除会话消息及关联文件
- 优化发布流程：SQLite 原生模块随包发布，并在 macOS/Windows 原生环境打包

## v2.0.9.2 (2026-10-09)

- 开源源码仓库，新增三语 README、MIT License、贡献指南和开发文档
- 修复 CI 测试依赖安装顺序，确保测试先安装前端依赖

## v2.0.9.1 (2026-08-25)

- 新增自定义缓存目录：可在设置中修改缓存（上传文件）目录，支持迁移已有文件，重启后生效
- 缓存路径区域显示「自定义」标识，区分默认与自定义路径

## v2.0.9.0 (2026-08-08)

- 新增自定义昵称功能：登录时可输入昵称，聊天中可随时修改，所有端实时同步
- 新增自定义群名称功能：任意成员可修改群名称，所有端实时同步
- 新增用户 IP 显示：每条消息发送者昵称下方显示其局域网 IP 地址
- 新增在线人数显示：聊天头部显示当前在线人数
- 优化登录流程：支持昵称缓存，下次进入自动填充

## v2.0.8.9 (2026-06-16)

- 新增问题反馈功能：在首页底部和常用功能侧边栏新增问题反馈入口，点击可直接跳转到 GitHub Issue 页面
- 优化用户反馈渠道：方便用户提交问题和建议，帮助持续改进产品

## v2.0.8.8 (2026-05-24)

- 新增 Pin 消息功能，支持将重要消息固定在顶部
- 新增批量文件拖拽上传功能
- 优化消息气泡展示效果
- 修复部分已知问题
