
# ChatTransfer 演示视频脚本

## 视频长度
建议 2 分 40 秒左右

---

## 中文旁白与字幕

### 1. 片头（0:00–0:08）
**画面**：Logo/标题卡（或直接进入桌面）  
**旁白**：  
“这是 ChatTransfer，一个为开发和测试场景设计的局域网互传工具。免安装，扫码即连，用完即走。”  
**字幕**：  
ChatTransfer：局域网互传 & 聊天工具｜免安装｜扫码即连

### 2. 场景 1：启动与扫码（0:08–0:28）
**画面**：双击启动应用 → 浏览器打开首页 → 出现二维码  
**旁白**：  
“在电脑上启动后，会自动打开页面并生成二维码。手机扫码，就能直接进入聊天页面。”  
**字幕**：  
启动即生成二维码｜手机扫码直接进入

### 3. 场景 2：文字/链接互传（0:28–0:48）
**画面**：电脑端发送一段文本 + 一个 URL；手机端实时收到  
**旁白**：  
“发文字、发链接都非常快。开发联调时的配置片段、调试链接，直接从电脑发到手机。”  
**字幕**：  
文字/链接秒级互传｜电脑 → 手机

### 4. 场景 3：文件/图片拖拽上传（0:48–1:15）
**画面**：拖一个图片或文件到聊天窗口上传 → 手机端下载/打开  
**旁白**：  
“支持拖拽上传图片和文件。比如测试包、截图、录屏，都可以直接丢进来传过去。”  
**字幕**：  
拖拽上传｜图片/文件快速传输

### 5. 场景 4：任意消息生成二维码（1:15–1:35）
**画面**：选中一条消息 → 生成消息二维码 → 用另一台设备扫码打开/查看  
**旁白**：  
“每条消息都可以生成二维码。你可以把链接或内容变成二维码，让同事直接扫码打开。”  
**字幕**：  
任意消息 → 二维码｜扫码即用

### 6. 场景 5：Pin 与置顶（1:35–1:55）
**画面**：选中重要消息 → 点击 Pin/置顶 → 消息置顶显示 → 点击置顶消息快速定位  
**旁白**：  
“支持 Pin 和置顶功能，可以将重要消息置顶，需要时点击可快速定位到该消息。”  
**字幕**：  
Pin & 置顶｜重要消息快速找到

### 7. 场景 6：一对多互发文件（1:55–2:15）
**画面**：多个设备同时在线 → 电脑端发送文件 → 所有手机同时收到  
**旁白**：  
“支持一对多互发各种文件。多设备同时在线，文件可以同时发送给所有人。”  
**字幕**：  
一对多传输｜多设备同时接收

### 8. 场景 7：隐私与本地保存（2:15–2:30）
**画面**：打开设置 → 显示缓存目录/打开缓存目录（如有）  
**旁白**：  
“所有内容默认只在本地保存，并且只在局域网内传输。不走第三方云服务，更放心。”  
**字幕**：  
本地保存｜局域网传输｜不走第三方云服务

### 9. 片尾：引导下载与反馈（2:30–2:40）
**画面**：Releases 页面 / README / Issues 页面  
**旁白**：  
“软件长期免费。欢迎下载体验，也欢迎在 Issues 里给我建议，帮助它变得更好。”  
**字幕**：  
免费下载｜欢迎提 Issue 反馈

## English Narration and Subtitles

### 1. Opening (0:00–0:08)
**画面**：Logo/Title card (or directly to desktop)  
**Narration**：  
“This is ChatTransfer, a LAN file transfer and chat tool designed for development and testing. No installation required, scan to connect, use and go.”  
**Subtitle**：  
ChatTransfer: LAN file transfer & chat | No install | Scan to connect

### 2. Scene 1: Launch and Scan QR (0:08–0:28)
**画面**：Double-click to launch app → Browser opens homepage → QR code appears  
**Narration**：  
“After launching on your computer, it will automatically open a page and generate a QR code. Scan with your phone to enter the chat page directly.”  
**Subtitle**：  
QR code on launch | Phone scan to enter directly

### 3. Scene 2: Text/Link Transfer (0:28–0:48)
**画面**：Computer sends text + URL; phone receives in real-time  
**Narration**：  
“Sending text and links is very fast. Configuration snippets, debug links from development can be sent directly from computer to phone.”  
**Subtitle**：  
Text/link instant transfer | Computer → Phone

### 4. Scene 3: Drag and Drop Upload (0:48–1:15)
**画面**：Drag image/file to chat window → Phone downloads/opens  
**Narration**：  
“Drag and drop images and files for upload. Test packages, screenshots, screen recordings can all be directly dragged and transferred.”  
**Subtitle**：  
Drag and drop upload | Fast image/file transfer

### 5. Scene 4: Any Message → QR Code (1:15–1:35)
**画面**：Select message → Generate QR code → Another device scans to open/view  
**Narration**：  
“Every message can generate a QR code. You can turn links or content into QR codes for colleagues to scan and open directly.”  
**Subtitle**：  
Any message → QR Code | Scan to use

### 6. Scene 5: Pin & Pin to Top (1:35–1:55)
**画面**：Select important message → Click Pin/Pin to Top → Message stays pinned → Click pinned message to quickly navigate  
**Narration**：  
“Supports Pin and Pin to Top features. Important messages can be pinned, and clicking them quickly navigates to the message.”  
**Subtitle**：  
Pin & Pin to Top | Find important messages quickly

### 7. Scene 6: One-to-Many File Transfer (1:55–2:15)
**画面**：Multiple devices online simultaneously → Computer sends file → All phones receive at once  
**Narration**：  
“Supports one-to-many file transfer. Multiple devices online simultaneously, files can be sent to everyone at once.”  
**Subtitle**：  
One-to-many transfer | Multiple devices receive simultaneously

### 8. Scene 7: Privacy & Local Storage (2:15–2:30)
**画面**：Open settings → Show cache directory/open cache directory (if available)  
**Narration**：  
“All content is only saved locally by default and only transferred within the LAN. No third-party cloud services, more secure.”  
**Subtitle**：  
Local storage | LAN transfer | No third-party cloud

### 9. Closing: Download & Feedback (2:30–2:40)
**画面**：Releases page / README / Issues page  
**Narration**：  
“The software is free forever. Welcome to download and try, and feel free to give suggestions in Issues to help it improve.”  
**Subtitle**：  
Free download | Welcome to submit Issues feedback
