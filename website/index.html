QUICK ANSWERS

关于 ChatTransfer，你可能想问

ChatTransfer 是什么？

ChatTransfer（聊天快传）是一款免费、MIT 开源的局域网聊天与文件互传工具，面向开发者、测试人员和小团队。电脑启动服务，其他设备通过浏览器加入，即可实时分享文字、图片和文件。

ChatTransfer 收费吗？

完全免费。项目采用 MIT 开源许可证，源码在 GitHub 公开；作者在仓库中说明软件长期免费。无需购买订阅。

手机需要安装 App 或注册账号吗？

不需要。电脑运行 ChatTransfer 后，手机连接同一局域网，扫码即可在现代浏览器中加入。电脑需要先运行可执行文件，或通过 npm 启动服务。

支持哪些系统？

预编译可执行文件支持 Windows 10+ 和 macOS 10.15+，仓库列出的发布包为 x64。手机和其他设备通过现代浏览器使用。Node.js 20.17+ 环境可通过 npx chattransfer 运行；Linux 无桌面环境可使用 --no-browser。

能传哪些内容？有大小限制吗？

支持文字、图片和各类文件，可批量拖拽上传，适合传日志、截图、录屏、配置片段和测试包。文件大小受服务端配置限制，并非无限大小；实际速度取决于设备和网络。传输安装包不等于自动安装。

扫码后页面打不开怎么办？

先确认手机和运行服务的电脑处于同一局域网，并确认服务仍在运行。文件上传失败时，检查文件是否超过服务端配置的大小限制。

内容会上传云端吗？

本地局域网部署无内置云存储，记录和文件默认保存在运行服务的本机。在线体验是远程部署，内容会发送到体验服务器，不能等同于本地传输。

是端到端加密或 P2P 吗？

默认不是。浏览器连接 ChatTransfer 服务，传输安全取决于部署方式；建议只在可信局域网或 HTTPS 反向代理后使用。

在线体验和下载使用有什么区别？

在线体验让你先了解界面和交互，需要连接远程体验服务器；下载后可在自己的电脑启动局域网服务。体验入口采用 HTTP，请仅使用非敏感的演示内容。
