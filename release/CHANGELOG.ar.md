# سجل التغييرات

جميع التغييرات البارزة في هذا المشروع. الإصدار الحالي: **v2.0.11**

## v2.0.11 (2026-10-18)

- إصلاح معالجة سطر الأوامر للمنفذ الافتراضي كمنفذ محدد يدويًا، مع استعادة إعادة المحاولة التلقائية عند عدم توفر المنفذ
- تغيير المنفذ الافتراضي من 55555 إلى 55556 لتجنب منفذ محجوز بواسطة macOS
- إرجاع رمز خروج غير صفري عند فشل بدء التشغيل لتسهيل الاستخدام في السكربتات وأتمتة العمليات

## v2.0.10 (2026-10-18)

- إضافة طريقة التوزيع عبر npm مع دعم `npx chattransfer` و`npm install -g chattransfer`
- إضافة خيارات سطر الأوامر: `--host` و`--port` و`--data-dir` و`--public-url` و`--no-browser` و`--version` و`--help`
- إضافة سير عمل تلقائي للنشر على npm يشغّل الاختبارات ويبني الواجهة ويتحقق من محتوى الحزمة قبل النشر
- تحسين مجلدات بيانات وقت التشغيل في npm بحيث لا تُكتب الإعدادات والملفات المرفوعة وبيانات SQLite داخل مجلد الحزمة العام
- إصلاح توافق التشغيل على Linux بدون واجهة رسومية وتفعيل دعم `xdg-open` للمتصفح ومجلد التخزين المؤقت

## v2.0.9.3 (2026-10-11)

- إضافة سجل محادثات على جانب الخادم باستخدام SQLite: تُحفظ رسائل المجموعة والمحادثات الخاصة، ويمكن للأجهزة الجديدة والأجهزة غير المتصلة مزامنة السجل بعد الاتصال
- إضافة مزامنة تزايدية للسجل باستخدام المؤشر مع إزالة تكرار الرسائل، وإصلاح فراغ فقاعات النص للرسائل المستعادة
- إضافة «مسح سجلي المحلي» و«مسح سجل المحادثة على الخادم»؛ الخيار الأخير يحذف رسائل المحادثة والملفات المرتبطة بها
- تحسين عملية الإصدار: تُضمَّن وحدة SQLite الأصلية مع الحزمة، وتُبنى الحزم على أنظمة macOS/Windows الأصلية

## v2.0.9.2 (2026-10-09)

- فتح مستودع الشيفرة المصدرية مع README بثلاث لغات ورخصة MIT ودليل المساهمة ووثائق التطوير
- إصلاح ترتيب تثبيت تبعيات CI بحيث تُثبَّت تبعيات الواجهة قبل تشغيل الاختبارات

## v2.0.9.1 (2026-08-25)

- إضافة مجلد تخزين مؤقت مخصص: يمكن تغيير مجلد التخزين المؤقت (الرفع) في الإعدادات، مع خيار نقل الملفات الموجودة، يُطبق بعد إعادة التشغيل
- يعرض مسار التخزين المؤقت الآن علامة «(مخصص)» للتمييز بين المسارات المخصصة والافتراضية

## v2.0.9.0 (2026-08-08)

- إضافة لقب مخصص: أدخل لقبًا عند تسجيل الدخول، يمكن تغييره في أي وقت، ومزامنته عبر جميع الأجهزة في الوقت الفعلي
- إضافة اسم مجموعة مخصص: يمكن لأي عضو إعادة تسمية المجموعة، ومزامنته عبر جميع الأجهزة في الوقت الفعلي
- إضافة عرض عنوان IP للمستخدم: تُظهر كل رسالة عنوان IP للشبكة المحلية للمُرسل أسفل لقبه
- إضافة عدد المتصلين: يُظهر رأس المحادثة عدد المستخدمين المتصلين الحاليين
- تحسين تدفق تسجيل الدخول: يتم حفظ اللقب ملءً تلقائيًا في المرة القادمة

## v2.0.8.9 (2026-06-16)

- إضافة ميزة التغذية الراجعة: إدخال جديد للتغذية الراجعة في الجزء السفلي من الصفحة الرئيسية وشريط الأدوات الشائع، انقر للانتقال مباشرة إلى صفحة مسائل GitHub
- تحسين قناة التغذية الراجعة للمستخدم: مناسبة للمستخدمين لتقديم المشاكل والاقتراحات، مما يساعد على تحسين المنتج بشكل مستمر
